Entrar al panel

Pegue aquí la llave de acceso de GitHub de esta página. La llave solo sirve para la página de POLIANDES y queda guardada únicamente en este equipo.

¿No tiene la llave? Cómo crearla (una sola vez)
  1. Inicie sesión en GitHub y abra esta página para crear la llave.
  2. En Token name escriba: Panel POLIANDES. En Expiration elija No expiration (o la fecha que prefiera).
  3. En Repository access elija Only select repositories y marque solo el repositorio poliandes-web.
  4. En Permissions → Repository permissions, busque Contents y cámbielo a Read and write. No active nada más.
  5. Pulse Generate token, copie la llave (empieza por github_pat_) y péguela arriba.

Puede darle la misma llave a la persona de POLIANDES que actualizará la página. Guárdela en un lugar seguro; si la pierde o cree que alguien la vio, bórrela en GitHub y cree otra igual.
